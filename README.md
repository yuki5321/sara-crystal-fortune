# SARA's クリスタル星占い 🔮✨

高学年〜中高生の女の子向けに作られた、明るく透明感のある夢かわいいWeb占いツールです。
単一の `index.html` ファイルの中に、HTML5 / CSS3 / JavaScript、Web Audio API（Lo-Fi BGMエンジン）、および高画質お守り壁紙コレクションが美しく内包されています。

---

## 🌟 特徴とこだわり

### 1. 「明るくかわいいSARAワールド」デザイン
- **ミルキーラベンダー×パステルピンクの澄んだグラデーション**
  - 暗いトーンを使わず、日中の光が透き通るような明るい世界観。
  - テキストはディープパープル（#3b0764等）を採用し、可読性と高いコントラストを確保。
- **ぷっくり可愛いフロストガラス（すりガラス効果）**
  - `backdrop-filter: blur(16px)` と微細なインセットシャドウによる立体的なガラスカードUI。
- **キャンディ風ぷっくりボタン**
  - ツヤ感のあるハイライト反射とバウンスアニメーション。
- **ふわふわ浮かぶシャボン玉＆星屑の背景アニメーション**
  - CSSキーフレームによるパステル調のパーティクル。

### 2. 音と癒やし（Web Audio API）
- **🎧 放課後Lo-Fi（BGM再生/停止）**
  - 外部音源ファイルへの依存ゼロ！ブラウザ組み込みの Web Audio API により、エモいFMエレピ／チャイム／Lo-Fiアルペジオが流れます。
- **きらめき効果音（SE）**
  - ボタンをタップしたときに鳴る、透明感のあるクリスタルチャイム音。

### 3. しいたけ占い風・心に刺さる3層メッセージ（全12星座完全対応・全年代対応）
- **生年月日の全年代対応**
  - 1920年〜現在の年まで、子どもから大人・お年寄りまで誰でも自分の生年月日で占えます。
- **生まれた時間帯別の完全パーソナライズ**
  - 「朝」「昼」「夜」「秘密」の4つの時間帯ごとに、専用の守護光バッジ、心境のささやき、優しい処方箋、ラッキーアクション＆アイテム、オーラメーターのバランスがダイナミックに変化します。
- **① 守護クリスタル＆オーラカラー**
  - 宝石アイコン、石言葉、オーラカラー、4項目のオーラメーター（アニメーション）。
- **② 今のあなたの心境・星のささやき**
  - 学校生活や日常の人間関係、がんばり屋さんの心に深く寄り添った描写。
- **③ 星からの優しい処方箋**
  - 「無理に合わせなくて大丈夫」「今日は30点で超はなまる」などの全肯定メッセージ。
- **④ 放課後ラッキーアクション＆アイテム**
  - 気軽に試せるプチアクション、お守りアイテム、ハッピースポット、ラッキーナンバー＆カラー。

```bash

python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
